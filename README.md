## Image Classification Project

### Description

This project compares three machine learning models for image classification: Naive Bayes, Decision Tree, and MLP Neural Network.
Images are preprocessed and evaluated using standard performance metrics.

### Technologies

* Python
* NumPy
* Scikit-learn
* PIL

### Features

* Image preprocessing (resize, grayscale, normalization)
* Model training (NB, DT, MLP)
* Performance evaluation (accuracy, precision, recall, F1-score)
* Confusion matrix visualization

### Results

MLP achieved the highest accuracy compared to Naive Bayes and Decision Tree.

### How to Run

1. Install dependencies
2. Set dataset path in the code
3. Run:

```bash
python app.py
```
